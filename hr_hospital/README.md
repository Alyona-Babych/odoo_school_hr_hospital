# HR Hospital Module

This module extends Odoo to manage hospital operations.

## Features

* Manage Doctors
* Manage Patients
* Manage Diseases
* Track Patient Visits

## Technical Details

* Custom models for all entities
* Tree and Form views for each model
* Access rights for internal users
* Predefined master and demo data

## Installation

1. Place the module in the `custom_addons` directory
2. Update app list in Odoo
3. Install the module

## Requirements

* Odoo 19
